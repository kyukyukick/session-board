# セッションボード

クトゥルフ神話TRPG（第6版）のオフラインセッションを補助するWebアプリです。GMのパソコンで操作し、プレイヤーに見せる画面を外部モニターや画面共有で表示します。

## 使い方

1. `index.html` をChromeかEdgeで開きます（GitHub Pagesで公開している場合はそのURLを開きます）。
2. 右上の「プレイヤー画面を開く」で別ウィンドウを開き、外部モニターへ移動します。ダブルクリックか F キーで全画面になります。
3. GM画面で操作すると、プレイヤー画面にすぐ反映されます。

## できること

- コマ：画像・名前・ステータス（HP／MP／SANなど）・イニシアティブ（行動順）の設定、手番とラウンドの管理
- 公開と秘匿：コマやマーカーごとにプレイヤー画面へ出すかどうかを切り替え
- 盤面：格子状の前景（マップ）と画面全体の背景、画像マーカー、テキスト、拡大縮小と移動
- シーン：前景・背景・BGM・マーカーをまとめて保存し、ワンクリックで切り替え
- チャット：メイン／情報／雑談／秘話のタブ、公開メモとGMメモ、メッセージウィンドウ
- ダイス：BCDice（クトゥルフ神話TRPG）のコマンド、3Dダイスの演出
- BGM：音源の取り込み、ループ再生、音量調節
- スマホ表示：プレイヤーが自分のスマホで、マップ・ステータス・チャット・自分宛ての秘話を見られる（QRコードで参加、見るだけ）
- 探索者メーカーの「ココフォリア駒」出力の取り込み
- ルームの書き出し／読み込み（画像・音源込みのバックアップ）

## データの扱い

- ルームの内容（コマ、画像、音源、チャットなど）は、使っているブラウザの中にだけ保存されます。サーバーには送信されません。
- 別のパソコンやブラウザへ移すときは「書き出し」「読み込み」を使ってください。
- スマホ表示を有効にしたときだけ、GM画面とスマホをWebRTCで直接つなぎます。相手を見つけるために [PeerJS](https://peerjs.com/) の公開サーバーを使い、プレイヤーに見せてよい情報だけをスマホへ送ります。スマホ用のURLを知っている人は誰でも見られるので、参加者にだけ伝えてください。
- ダイスは有志が公開している BCDice-API サーバーに問い合わせて振ります。送信するのはダイスコマンドらしい文（半角英数記号で始まり数字を含むもの）だけです。接続できないときは内蔵のダイスに切り替わります。
